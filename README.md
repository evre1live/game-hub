# Три комнаты

Главная страница клуба настольных игр: три 3D-комнаты, каждая в своём стиле. Наведите на комнату — она подсветится, нажмите — камера подлетит к ней, а справа (на телефоне — снизу) появится описание и кнопка «Играть».

| Комната | Игра | Адрес |
|---|---|---|
| 01 · Салун | Дикий Запад | https://dikiy-zapad.onrender.com |
| 02 · Лаунж | ГРЯЗЬ | https://gryaz.onrender.com |
| 03 · Подземелье | Под Землёй | https://podzemlei.onrender.com |

## Как устроено

- `public/index.html` — готовая страница, один файл. Её и публикует Render.
- `src/index.html` — разметка и стили, `src/app.js` — 3D-сцена (three.js r160) и интерфейс.
- Вся графика процедурная: мебель собирается в коде, текстуры (доски, камень, плакаты, вывеска, карты) рисуются на canvas. Из сети грузятся только three.js с jsDelivr и шрифты Google Fonts.
- Пока гость читает описание игры, страница заранее будит её сервер: бесплатный Render усыпляет игры без игроков.
- Ссылки на комнаты: `#dikiy-zapad`, `#gryaz`, `#podzemlei`.
- Управление: клик или тап по комнате, перетаскивание — поворот, клавиши `1`–`3`, стрелки, `Esc` — назад, двойной клик — вернуть ракурс.
- Без WebGL страница показывает обычные карточки игр.

## Как поменять

Названия, описания, адреса игр и факты — массив `GAMES` в начале `src/app.js`. После правок:

```bash
node tools/build.js        # пересобрать public/index.html
```

Render при каждом пуше в `main` сам пересобирает и обновляет сайт.

## Проверка

```bash
npm install
npx playwright install chromium
npm run build
npm test                   # наведение, клики, клавиши, ссылки, переход в игру, работа в рамке
npm run images             # пересоздать public/og.png и public/apple-touch-icon.png
```

## Запуск на Render

1. Render → **New → Blueprint** → репозиторий `evre1live/game-hub`.
2. Render прочитает `render.yaml` и создаст бесплатный статический сайт `game-hub`.
3. Если адрес получится не `game-hub.onrender.com`, поправьте `og:image` в `src/index.html` и пересоберите.
